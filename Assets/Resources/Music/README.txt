배경음악 넣는 곳 (MusicPlayer.cs)

이 폴더에 아래 이름으로 음악 파일을 넣으면 코드 수정 없이 바로 나옵니다.
확장자는 상관없음(.ogg 추천, .mp3 / .wav 가능). 이름만 정확히 맞추면 됩니다.
파일이 없는 곳은 지금처럼 조용합니다. 모든 곡은 반복 재생되고, 장소가 바뀌면 1.2초 동안 겹쳐 넘어갑니다.

  Lobby     로비(걸어 다니는 허브, 연금술사 상점 포함)
  Casino    도박장(슬롯)
  Gacha     뽑기 상점
  Dungeon   일반 방 + 타이틀(같은 곡)
  Puzzle    퍼즐 방(얼음 미끄럼·함정 복도·룬 순서·상자 밀기·전투 퍼즐)
  MiniGame  미니게임 방(상자 섞기·두더지 잡기·황금 고블린 추격·보물 찾기·버티기)
  Mural     횃불로 연 잊힌 벽화의 방
  Boss1     1층 보스방 (거대 멧돼지)
  Boss2     2층 보스방 (오우거)
  Boss3     3층 보스방 (돌 골렘)
  Boss4     4층 보스방 (슬라임 킹)
  Boss5     5층 보스방 (버섯 군주)
  Boss6     6층 보스방 (망령 궁수)
  Boss7     7층 보스방 (그림자 암살자)
  Boss8     8층 보스방 (미노타우로스)
  Boss9     9층 보스방 (리치)
  Boss10    10층 보스방 (거울 가면 기사)
  Knight    히든 몹 기억하는 기사가 나온 방 (10-23 연결됨 - 기사가 나타나면 이 곡, 잡거나 방을 나가면 일반 방 곡)

음악이 나오지 않는 곳: 보스를 잡은 뒤(서서히 꺼짐), 아직 파일이 없는 곳.
볼륨: 설정 > 배경음악 (전체 볼륨도 함께 적용). 자동 플레이 봇 실행 중엔 음악을 틀지 않습니다.

Unity 가져오기 설정 추천: Load Type = Streaming, Compression = Vorbis, 품질 70% 정도.
